# 2026-03-06 - Proxy Server Fix

## Problem
The Node.js proxy server on port 4173 was crashing silently, causing 504 Gateway Timeout errors. This broke the entire dashboard chain:
Browser → ngrok → Proxy (4173) → Backend (8000)

## Solution Implemented
**PM2 Auto-Restart Configuration (Option 1)**

### Changes Made

1. **Created PM2 ecosystem file** at `/data/workspace/frontend/ecosystem.config.cjs`:
   - `autorestart: true` - Auto-restart on crash
   - `max_restarts: 10` - Limit restarts to prevent restart loops
   - `min_uptime: '10s'` - Must stay up 10s to count as stable
   - `restart_delay: 3000` - Wait 3s before restarting
   - `max_memory_restart: '500M'` - Restart if memory exceeds 500MB
   - `exp_backoff_restart_delay: 100` - Exponential backoff for rapid crashes

2. **Started proxy with PM2**:
   ```bash
   cd /data/workspace/frontend && pm2 start ecosystem.config.cjs
   pm2 save
   ```

3. **Configuration persisted** to `/home/openclaw/.pm2/dump.pm2`
