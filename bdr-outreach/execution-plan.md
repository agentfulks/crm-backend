## Daily Execution Checklist

### Morning (30 min)
- [ ] Select 10 studios from "Ready for Review" (prioritize Tier-1, then Tier-2)
- [ ] Quick validation: Check their App Store/Google Play for recent updates (live ops signal)
- [ ] Verify contact still holds role (LinkedIn quick check)

### Outreach Block (60 min)
- [ ] Draft personalized message for each (reference specific game, update, or news)
- [ ] Use Trello card data — personalization hook already researched
- [ ] Send manually via email (Lucas)
- [ ] Move card to "Sent" column immediately after sending
- [ ] Log send date in card description

### End of Day (15 min)
- [ ] Review "Sent" column for any Day 3 follow-ups needed
- [ ] Prepare value-add content for Day 7 follow-ups (industry insights, relevant reports)
- [ ] Update tracker with day's activity count

## Follow-up Cadence

| Day | Action | Template |
|-----|--------|----------|
| **Day 0** | Initial outreach | Personalized hook + value hypothesis + soft CTA |
| **Day 3** | Quick bump | "Wanted to make sure this didn't get buried — still think there's a fit here" |
| **Day 7** | Value-add | Share relevant insight: "Saw [their game] just hit top 10 — thought you'd find this [industry report/insight] useful" |
| **Day 14** | Final attempt or archive | "Last touch — happy to reconnect when timing is better" → Move to "Archive" if no response |

### Follow-up Rules
- **No response after 14 days** → Move to "Archive" list
- **Positive reply** → Move to "Active Conversations" + schedule call
- **Negative reply** → Note reason in card, move to "Not Now" (tag with reason)

## Quick Qualification Signals

### ✅ Prioritize These
- Recent funding announcement (6–12 months)
- Active hiring for "Live Ops" roles
- Monthly content updates visible in App Store
- New game launch in last 90 days
- Partnerships/BD role posted on LinkedIn

### ⚠️ Deprioritize
- No updates in 6+ months
- Pure ad networks (no games)
- < 20 employees with no live ops evidence
- Publisher-only (no internal dev)
